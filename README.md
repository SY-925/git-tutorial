# Speculative Sampling & Knowledge Distillation

Research portfolio for efficient LLM inference.

## Research Focus

This project focuses on two interconnected areas in large language model optimization:

- **Speculative Sampling** — Accelerating LLM inference via the draft-and-verify paradigm, using a small draft model to propose candidate tokens verified in parallel by the target model.
- **Knowledge Distillation** — Compressing large teacher models into compact students, specifically optimized as draft models for speculative decoding.
